# App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the bare `_authed.tsx` header with an industry-standard responsive app shell: a desktop sidebar rail carrying the boards list plus a pinned account control, and a mobile context-aware top app bar, so opening a board on desktop is a two-pane master/detail and on mobile stays a list-to-detail stack.

**Architecture:** Build out the empty `navigation` feature slice by mirroring the proven Mahlzeit shell (`/home/maikb/IdeaProjects/mahlzeit/src/features/navigation/`), diverged for Pinnwand's single destination. One responsive `NavigationShell` renders both layouts and lets Tailwind breakpoints decide visibility (`hidden md:flex` rail, `md:hidden` top bar). No JS user-agent sniffing. The shell mounts inside `_authed.tsx`, so every child is an authed route and no chromeless-route guard is needed. No bottom tab bar (Pinnwand has one top-level destination; a tab bar is deferred until a real second destination lands).

**Tech Stack:** React 19, TanStack Router (file-based), Tailwind CSS 4, Base UI primitives (`@base-ui/react`) styled as shadcn components with our Modern Minimal tokens, lucide-react icons, Vitest + Playwright.

## Global Constraints

- No em dashes in any authored prose or copy. German UI strings live in `src/features/navigation/lib/copy.ts` as named constants (SCREAMING_SNAKE_CASE).
- Base UI, not Radix. New primitives are authored under `src/shared/components/ui/` on `@base-ui/react` equivalents, styled with existing theme tokens (`bg-card`, `bg-accent`, `bg-popover`, `text-popover-foreground`, `border-border`, `ring-ring`). Mirror Mahlzeit's already-translated versions; do not `pnpm dlx shadcn add` (that pulls Radix).
- Strict TypeScript: no `any`, no `as unknown as X`, `import type` for type-only imports (verbatimModuleSyntax + exactOptionalPropertyTypes are on).
- Layer boundaries: `components/` never imports `api/` or `@supabase/*`; the rail reads boards through the `@/features/boards` barrel (`useMyBoards`), never a deep import. Routes import features through their `index.ts`.
- Mobile-first: base classes are mobile, `md:` scales up. Touch targets at least 44x44 (`min-h-11`). Input font-size at least 16px (avoid iOS zoom).
- PWA safe areas: top chrome pads `pt-[max(env(safe-area-inset-top),0.75rem)]`; the rail's pinned bottom block pads `pb-[max(env(safe-area-inset-bottom),0.75rem)]`. `viewport-fit=cover` is already set.
- Test behavior via ARIA roles + copy constants, never hardcoded UI strings or pixel assertions. Full-slice completeness: loading / error / empty states present; no TODOs, stubs, or placeholder menu items that route nowhere.
- Account menu ships identity + Sign out only. No Profile or Theme items yet (`profile`/`appearance` are empty stubs with no routes; a menu item to a nonexistent route violates the no-placeholder rule). They join when their slices land.

```ts
import { useRouterState } from "@tanstack/react-router";

const BOARD_PATH = /^\/boards\/([^/]+)$/;

/** The open board id, parsed from the pathname; null on the list root or a
 * non-board route (e.g. /boards/join). Derived from the route, never local
 * state, so deep links and back/forward highlight the right rail item. */
export function activeBoardIdForPath(pathname: string): string | null {
  const match = BOARD_PATH.exec(pathname);
  if (!match) {
    return null;
  }
  const [, id] = match;
  return id === "join" ? null : id;
}

export function useActiveBoardId(): string | null {
  return useRouterState({
    select: (state) => activeBoardIdForPath(state.location.pathname),
  });
}
```

- [ ] **Step 3: Write `lib/account-identity.ts`.** Pinnwand has no `display_name`/profile feature yet, so identity comes from the session email only (no `useAccountEmail`, `useProfile`, or `member-avatar` helpers — those are Mahlzeit-only). Name is the email local-part; initials from the same:

```ts
import { useSession } from "@/features/auth";

const FALLBACK_INITIAL = "?";
const MAX_INITIALS = 2;

/** Up to two uppercased letters from an email local-part, for the avatar chip. */
export function initialsForEmail(value: string | null): string {
  const local = value?.split("@")[0]?.trim() ?? "";
  const letters = local.replace(/[^a-zA-Z]/g, "");
  if (letters.length === 0) {
    return FALLBACK_INITIAL;
  }
  return letters.slice(0, MAX_INITIALS).toUpperCase();
}

type AccountIdentity = {
  identityName: string;
  identityEmail: string | null;
  identityInitials: string;
};

export function useAccountIdentity(): AccountIdentity {
  const { user } = useSession();
  const email = user?.email ?? null;
  const identityName = email?.split("@")[0] ?? "";
  return {
    identityName,
    identityEmail: email,
    identityInitials: initialsForEmail(email),
  };
}
```
